# Google Apps Script セットアップ

edit ページからスプレッドシートを更新するために必要です。

## 手順

1. スプレッドシートを開く  
   https://docs.google.com/spreadsheets/d/1xFpRa3bgWPabH5dVZynlX19tFLnohjE15YcZs3jOqGQ/edit

2. **拡張機能 → Apps Script**

3. `gas/Code.gs` の内容を貼り付けて保存

4. **デプロイ → 新しいデプロイ**
   - 種類: **ウェブアプリ**
   - 説明: masahoshi API
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**

5. 表示された URL を `config.js` の `API_URL` に設定

6. `npm run deploy` で再デプロイ
